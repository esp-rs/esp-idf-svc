Expand description

Gets the next AddressMapping info (using an iterator).

Available when OPENTHREAD_CONFIG_NAT64_TRANSLATOR_ENABLE is enabled.

@param[in] aInstance A pointer to an OpenThread instance. @param[in,out] aIterator A pointer to the iterator. On success the iterator will be updated to point to next NAT64 address mapping record. @param[out] aMapping A pointer to an otNat64AddressMapping where information of next NAT64 address mapping record is placed (on success).

@retval OT_ERROR_NONE Successfully found the next NAT64 address mapping info (@p aMapping was successfully updated). @retval OT_ERROR_NOT_FOUND No subsequent NAT64 address mapping info was found.
